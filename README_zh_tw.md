# 氚氫B站工具集

#### 介紹
這個程式是一款能夠快捷查詢B站一些使用者、影片等資訊和進行一些操作的小型工具集合。程式由氚氫（CQ-COMPLEX）開發，故名曰“氚氫B站工具集”。本程式使用的大部分API由Github的SocialSisterYi提供，專案地址：[https://github.com/SocialSisterYi/bilibili-API-collect](https://github.com/SocialSisterYi/bilibili-API-collect)。如果程式中的某些元素有侵權，請聯絡程式開發者CQ-COMPLEX，聯絡方式見文末。

專案始於2020年左右，具體開始時間已不可考。雖然已經歷經四五年，但仍然不是很完善，畢竟中間因學業鴿了很長時間……有段時間甚至差點忘了自己還有這麼個專案。。。但是現在來說應該不會忘了。當然，開發者將在2025年參加高考，屆時專案可能又會停滯。在此歡迎大家積極做出貢獻，提出寶貴建議！

工具有多種語言，能夠方便中國港澳臺地區同胞和外國友人檢視B站的一些資訊。目前只有簡體中文、繁體中文、英語文字能夠比較準確，其他語言目前依靠機器翻譯，目前使用必應翻譯和百度翻譯。機器翻譯必然存在一定的不準確性，所以歡迎各位外國網友協助修正程式翻譯文字，我們將感激不盡！當然，目前來說，其他語言的開發程度仍然比較低，總體來說，語言完整度為：簡體中文>英語>繁體中文>其他語言。

原始碼的更新代表了最新的開發進度，發行版則單獨釋出。


#### 軟體架構
本程式使用Python語言編輯；GUI介面使用Tkinter外掛簡便實現，介面經典復古；網路內容的獲取由requests元件實現。這個程式需要至少Python 3.6的環境才能執行。支援的Windows系統版本為：Vista、7、8、8.1、10、11，低於Windows Vista連Python 3.6都帶不動。當然目前來說推薦在Windows 10/11上使用，相容性最好。Vista推測是能用的，但不保證某些功能是否可以正常執行。


#### 安裝教程

程式無需安裝，即下即用，不過需要保證元件完整。
需要的檔案/資料夾如下：
1. avbv.py 用於av號和bv號的互轉（可離線操作，由Github的12345-mcpython提供），可以沒有，但是如果沒有，無法使用互轉功能。
2. foreign.py 為程式所必需，含有程式的部分文字，若丟失將無法執行。
3. icon.ico 程式圖示，丟失會無法執行。
4. initialize.txt 初始化檔案，用於設定初始字型（介面語言會在啟動時自動讀取系統語言），可以沒有，其內容可以按需更改。
5. lognew.py 程式更新日誌，可以沒有。
6. Topic.png 程式主題圖片，丟失會無法執行。
7. UsersEgg.py 查詢使用者中的彩蛋檔案，可以沒有。
8. 自訂字型（HarmonyOS Sans 系列、Noto Sans/Serif 系列）由系統提供，無需隨程式附帶；未安裝時程式會自動回退到系統預設字型。
