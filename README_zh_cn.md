# 氚氢B站工具箱

#### 介绍
这个程序是一款能够快捷查询B站一些用户、视频等信息和进行一些操作的小型工具集合。程序由氚氢（CQ-COMPLEX）开发，故名曰“氚氢B站工具箱”。本程序使用的大部分API由Github的SocialSisterYi提供，项目地址：[https://github.com/SocialSisterYi/bilibili-API-collect](https://github.com/SocialSisterYi/bilibili-API-collect)。如果程序中的某些元素有侵权，请联系程序开发者CQ-COMPLEX，联系方式见文末。

项目始于2020年左右，具体开始时间已不可考。虽然已经历经四五年，但仍然不是很完善，毕竟中间因学业鸽了很长时间……有段时间甚至差点忘了自己还有这么个项目。。。但是现在来说应该不会忘了。当然，开发者将在2025年参加高考，届时项目可能又会停滞。在此欢迎大家积极做出贡献，提出宝贵建议！

工具有多种语言，能够方便中国港澳台地区同胞和外国友人查看B站的一些信息。目前只有简体中文、繁体中文、英语文本能够比较准确，其他语言目前依靠机器翻译，目前使用必应翻译和百度翻译。机器翻译必然存在一定的不准确性，所以欢迎各位外国网友协助修正程序翻译文本，我们将感激不尽！当然，目前来说，其他语言的开发程度仍然比较低，总体来说，语言完整度为：简体中文>英语>繁体中文>其他语言。

源代码的更新代表了最新的开发进度，发行版则单独发布。


#### 软件架构
本程序使用Python语言编辑；GUI界面使用Tkinter插件简便实现，界面经典复古；网络内容的获取由requests组件实现。这个程序需要至少Python 3.6的环境才能运行。支持的Windows系统版本为：Vista、7、8、8.1、10、11，低于Windows Vista连Python 3.6都带不动。当然目前来说推荐在Windows 10/11上使用，兼容性最好。Vista推测是能用的，但不保证某些功能是否可以正常运行。


#### 安装教程

程序无需安装，即下即用，不过需要保证组件完整。
需要的文件/文件夹如下：
1. avbv.py 用于av号和bv号的互转（可离线操作，由Github的12345-mcpython提供），可以没有，但是如果没有，无法使用互转功能。
2. foreign.py 为程序所必需，含有程序的部分文本，若丢失将无法运行。
3. icon.ico 程序图标，丢失会无法运行。
4. initialize.txt 初始化文件，用于设定初始字体（界面语言会在启动时自动读取系统语言），可以没有，其内容可以按需更改。
5. lognew.py 程序更新日志，可以没有。
6. Topic.png 程序主题图片，丢失会无法运行。
7. UsersEgg.py 查询用户中的彩蛋文件，可以没有。
8. 自定义字体（HarmonyOS Sans 系列、Noto Sans/Serif 系列）由系统提供，无需随程序附带；未安装时程序会自动回退到系统默认字体。

#### 历史版本

**维护版 v0.14.1**

- “登录（二维码扫码）”直接显示二维码，用哔哩哔哩 App 扫码并确认即可。运行 `python -m pip install -r requirements.txt` 安装依赖。
